# Evaluations

Dated reports of live evaluation runs. Each run writes a Markdown report and a
JSON file with every case's result; both are committed so results can be
compared over time.

- `wod-YYYY-MM-DD.md`: the WOD parser against `evals/wod/cases.jsonl` (#155).
  How to run one is in [CONTRIBUTING](../../CONTRIBUTING.md#evaluating-the-wod-parser).

The notes are synthetic; no account's data is sent to a model or stored here.
